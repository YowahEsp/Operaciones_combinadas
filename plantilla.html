Operaciones combinadas

En cada paso se hace la operación u operaciones que tienen prioridad, y las demás no se tocan.

Ejemplos:
  1. 1.º Paréntesis y corchetes
  2. 2.º Multiplicaciones y divisiones
  3. 3.º Sumas y restas

Para multiplicar se puede escribir ·, * o x; para dividir, : o /. Con el teclado: → o Espacio avanza y ← retrocede. Esta versión trabaja con números naturales, paréntesis y corchetes.
